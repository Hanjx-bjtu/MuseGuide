# MuseGuide 人工评分材料

> 生成时间：2026-09-22 14:24 UTC
> 模型：真实 DeepSeek（非 Mock / 降级路径）
> 共 16 题。**请对照 `scores.csv` 逐题打分。**

## 评分方法

每题按 1~5 分评分（判据见 `docs/SCORING_GUIDE.md`）：

| 维度 | 含义 | 适用 |
|---|---|---|
| `theory_validity` | 理论上是否合理 | 全部 |
| `relevance` | 是否符合用户问题 | 全部 |
| `diversity` | 建议之间是否有差异（仅多方案题） | 仅多方案题 |
| `explainability` | 是否解释了原因 | 全部 |
| `groundedness` | 是否有知识依据 | 全部 |
| `usefulness` | 对创作者是否有帮助 | 全部 |
| `comprehensibility` | 零基础用户能否看懂 | 全部 |
| `actionability` | 用户能否据此行动 | 全部 |

> **不懂乐理也能评。** 大部分维度评的是「读起来是否清楚、是否回答了问题、
> 你是否愿意照着做」，这些不需要专业知识。
> 只有 `theory_validity`（理论上是否合理）需要乐理判断 —— 拿不准就留空，
> **留空比乱填更有价值**。

### gen.starter.001 —— §3.1.2 的核心示例

**用户输入**

```text
意图：我想写一首关于毕业的歌，有点伤感但最后是释然的感觉。
```

**系统输出**

- **调性**：C Major
  - 选 C 大调是因为它整体听起来温暖、明亮，像下午的阳光，但又不会太刺眼，很适合「伤感之后慢慢释然」这种情绪。
- **速度**：82 BPM
  - 82 的速度大概就是慢慢走路、翻相册的节奏，不快不慢，刚好能让人把情绪一点点铺开。
- **主歌**（偏伤感）
  - 和弦：Am → F → C → G
  - 这组和弦听起来像一个人坐在窗边回忆，有点闷闷的、舍不得的感觉。第一个 Am 听起来偏暗，像心里压着话；接着 F 和 C 让颜色稍微亮一点，但还没完全放开；最后一个 G 像话说到一半，悬在那里，等着往下走。
- **副歌**（转向释然）
  - 和弦：C → G → Am → F
  - 这组和弦听起来像终于抬起头、呼出一口气。第一个 C 很稳、很明亮，像告诉自己「没关系了」；G 推着往前走；Am 又轻轻拉回一点不舍；最后 F 停在一种温柔、开阔的感觉上，像把过去好好收起来。

**为什么这样选**：整首歌的安排就是「先说舍不得，再说往前走」。主歌用偏暗、偏柔和的 Am 开头，把伤感铺出来；副歌换回明亮的 C 开头，把情绪拉向释然。两段用的和弦其实差不多，只是顺序变了 —— 就像同一段回忆，先看到难过的那面，再看到放下的那面。速度保持中等偏慢，让情绪有空间慢慢转过来，不会太突然。

**如果你想调整**：
- 如果想让伤感更重一点，可以把主歌第一个 Am 换成 Am7，听起来会更柔、更闷，像话堵在胸口。
- 如果想让释然更明显，可以把副歌最后一个 F 换成 C，结尾会更稳、更确定，像真的放下了。
- 如果想加一点「中间转折」的感觉，可以在主歌和副歌之间加一个 G，像深呼吸一下再进副歌。

**理论依据**：
- [starter.song_structure.01] 一首歌是由几段拼起来的
- [starter.choosing_key_and_tempo.01] 先定「什么颜色」和「什么步速」
- [starter.how_to_start.01] 写歌其实只需要做四个决定
- [emotion.sad_to_hopeful.01] 伤感怎么变成释然
- [emotion.farewell_scene.01] 写「告别」这类歌，从哪下手

### gen.starter.002 —— 只做选择、不写字（§8 兜底路径）

**用户输入**

```text
意图：（未填写，仅做了选择）
选择：情绪=温柔 风格=民谣 速度=中等偏慢，像散步
```

**系统输出**

- **调性**：C Major
  - 选 C 大调是因为它听起来干净、温暖，不刺耳，而且钢琴上全是白键，弹起来最省事，新手不容易被黑键绊住。
- **速度**：82 BPM
  - 82 的速度差不多就是你平时散步的步速，不急不赶，正好装得下温柔这种慢慢流淌的情绪。
- **主歌**（温柔里带一点淡淡的低落）
  - 和弦：Am → F → C → G
  - 从 Am 开始，听起来像傍晚一个人走在小路上，有点心事但不沉重；接着 F 和 C 像轻轻叹了口气又缓过来；最后 G 把话说到一半停住，留个悬念，让人想听下一句。
- **副歌**（从低落转向释然、温暖）
  - 和弦：C → G → Am → F
  - 一上来就是 C，像太阳从云里露出来，情绪一下子打开了；G 推着你往前走，Am 稍微回头看了一眼，最后 F 稳稳地落下来，像终于把心里的话说完了，整个人松一口气。

**为什么这样选**：主歌用 Am 开头，先把你放进一个稍微暗一点、安静一点的空间里，适合慢慢讲故事；到了副歌换成 C 开头，同一个调但颜色变亮了，就像从屋里走到院子里，情绪自然就抬起来了。整首歌没有突然的大跳，都是顺着走，所以听起来一直是温柔的，只是主歌更收着，副歌更打开。

**如果你想调整**：
- 如果想让主歌更安静，可以把主歌第一个 Am 换成 Am7，听起来会更软、更雾一点，像隔了一层纱。
- 如果想让副歌更暖、更有拥抱感，可以把副歌最后一个 F 换成 Fmaj7，收尾会更亮、更舍不得结束。
- 如果觉得整首歌太平，可以在副歌的 G 那里稍微拖长一点点再进 Am，制造一个「憋一下再放开」的小高潮。

**理论依据**：
- [starter.choosing_key_and_tempo.01] 先定「什么颜色」和「什么步速」
- [starter.how_to_start.01] 写歌其实只需要做四个决定
- [starter.common_progressions.01] 不用自己设计，先套用现成的
- [starter.first_song_landing.01] 有了和弦之后，下一步做什么
- [emotion.tension_resolution.01] 先憋一口气，再呼出来

### gen.starter.003 —— 速度硬约束：用户选定 60 BPM，模型不得改成别的数

```text

```

**系统输出**

  - C 大调就像用白纸画画，所有音都摆在最顺手的位置，你不需要跟黑键较劲，能把注意力全放在情绪上。
- **速度**：60 BPM
  - 60 就是每秒一下，像翻相册时手指停在某张照片上的节奏，慢到能让每个音都沉下去。
- **主歌**（偏伤感、像在低声讲故事）
  - 和弦：Am → F → C → G
  - 从 Am 开始，听起来像一个人坐在窗边慢慢开口；F 让话里带点叹气的感觉；C 是短暂的安心，像翻到一张笑得开心的旧照片；G 又把心提起来，准备翻下一页。
- **副歌**（从伤感转向释然、像轻轻呼出一口气）
  - 和弦：C → G → Am → F
  - 这次从 C 开始，像抬起头来承认「都过去了」；G 把情绪推高一点；Am 再沉一下，是最后的不舍；F 收尾，像把相册合上，安静地放回抽屉。

**为什么这样选**：主歌用「先暗后亮再暗」的顺序，像翻相册时情绪起起伏伏，但始终没离开伤感；副歌把顺序倒过来，从最稳的 C 出发，最后落在 F 上，听起来像从「陷在回忆里」变成「带着回忆继续走」。速度定在 60，每个和弦都能停留足够久，情绪不会被赶着走。

**如果你想调整**：
- 如果觉得太苦，可以把主歌第一个 Am 换成 C，听起来会像「虽然难过但还能撑住」。
- 如果想让副歌更释然，可以把副歌最后一个 F 换成 C，结束感更强，像真的把相册合上了。

**理论依据**：
- [starter.choosing_key_and_tempo.01] 先定「什么颜色」和「什么步速」
- [starter.common_progressions.01] 不用自己设计，先套用现成的

### gen.starter.008 —— 零基础用户的常见起点

**用户输入**

```text
意图：我完全不会乐理，想写第一首歌
```

**系统输出**

- **调性**：C Major
  - C 大调就像用最普通的白开水泡茶，温暖又不苦，而且钢琴上全是白键，你随便按都不会难听。
- **速度**：82 BPM
  - 82 的速度像散步时哼歌，比心跳慢一点，刚好能唱出温暖又不赶时间的感觉。
- **主歌**（温暖中带一点回忆的柔软）
  - 和弦：C → G → Am → F

  - 和弦：F → G → C → C
  - F 和 G 像爬一个小坡，然后连续两个 C 像走到平地上深吸一口气——听起来会有「到家了」的感觉，特别适合副歌最后一句唱完，让人心里踏实。

**为什么这样选**：主歌用 C-G-Am-F 是让情绪先绕一绕，像聊天时慢慢进入话题；副歌换成 F-G-C-C，是把绕出去的情绪收回来，最后停在 C 上，像一句话说完了。整体从「有点悬着」到「稳稳落下」，这就是温暖民谣最舒服的走法。

**如果你想调整**：
- 如果觉得副歌还不够亮，可以把最后一个 C 换成 Cmaj7，听起来会更柔和、更梦幻——走向没变，只是多了层质感。
- 如果想更伤感一点，把主歌的 C 换成 Am 开头，像把灯调暗一档，但副歌不用动，这样对比会更明显。

**理论依据**：
- [starter.how_to_start.01] 写歌其实只需要做四个决定
- [starter.first_song_landing.01] 有了和弦之后，下一步做什么
- [layman.what_is_progression.01] 和弦进行是什么
- [layman.emotion_and_harmony.01] 为什么换个和弦，情绪就变了
- [starter.common_progressions.01] 不用自己设计，先套用现成的

### gen.advice.001 —— §3.9.2 的核心示例

**用户输入**

```text
创作目标：保持温暖，但不要太普通
和弦进行：C | G | Am | F
要求保持：保持温暖
用户水平：some
```

**系统输出**

**分析**：当前作品是 C 大调下的 I–V–vi–IV 进行 进行（C | G | Am | F），这是流行抒情歌里使用最广的走向之一，稳定、通用、好记 [来源2]。它的优点是功能清晰、情绪温暖、容易上口；缺点是低音走向为 C → G → A → F，基本是四度/五度跳进，缺少连贯的线条感，因此容易显得「普通」 [来源3]。用户目标是保持温暖但不要太普通，所以最合适的改动方向是：在不破坏原有功能关系的前提下，优先用加音和换低音来增色，必要时再考虑替换或插入 [来源1]。

**问题**：
- 低音线以跳进为主（C → G → A → F），缺少平滑的级进下行，听感连贯性弱，这是它听起来普通的主要原因之一 [来源3]。
- 四个和弦全是三和弦，没有七音或九音带来的柔和、梦幻色彩，整体偏「直白」 [来源5]。
- I–V–vi–IV 进行 本身是最高频的通用走向，如果没有音色或低音上的设计，很容易被听成模板 [来源2]。

**建议 A：换低音 + 加七音，温暖又连贯**

- 和弦：`Cmaj7 | G/B | Am7 | Fmaj7`
- 特点：功能关系完全不变，只靠七和弦与低音级进下行提升柔和度与设计感，改动成本最低。
- 解释：通俗解释：每个和弦都从三和弦变成七和弦，听起来会更软、更梦幻，像给画面加了一层柔光；同时把 G 换成 G/B、F 换成 F/A 之后，低音变成 C → B → A → A，形成一条平滑下行的线，整段音乐会更有「被设计过」的感觉，但温暖的基本情绪没有丢。
- 依据：三和弦加七音变成七和弦，不会改变功能关系，Cmaj7 仍然是 I 级、仍然稳定，只是听感更柔和 [来源5]。；换低音（转位）可以在和声实质不变的前提下增加连贯性与设计感，是改动成本很低的增色手段 [来源1]。；C → G/B → Am → F/A 的低音级进下行，是流行抒情歌中高频出现的「有设计感」写法 [来源2]。

**建议 B：最后一步借用平行小调的 iv**

- 和弦：`C | G | Am | Fm`
- 特点：只改最后一个和弦，把 F 换成 Fm，从平行小调借来 iv，保留前三个和弦的温暖，结尾多一层阴影。
- 解释：通俗解释：前三个和弦还是原来的 C → G → Am，温暖不变；最后一步把 F 换成 Fm，会突然多一丝忧伤和「电影感」，像阳光里飘过一片云。这种改动比加七音更明显，但仍然没有破坏 I → V → vi 的框架。
- 依据：把 IV 换成 iv 属于调式借用（Modal Borrowing），引入新的色彩但不破坏原有框架 [来源1]。；C → G → Am → Fm 是流行/抒情歌中常见的变体，最后一步借用平行小调的 iv，加一层阴影 [来源2]。

**建议 C：低音级进下行 + 七和弦 + 尾音借用**

- 和弦：`Cmaj7 | G/B | Am7 | Fmaj7 | Fm/Ab | C`
- 特点：在建议 A 的基础上再往前推一步，把低音线拉成 C → B → A → A → Ab → C 的完整下行，并让结尾落到 Fm/Ab 再回 C，温暖中带一点电影式收束。
- 解释：通俗解释：这条线把每个和弦的低音都串成一条平滑下行的楼梯，从 C 一路走到 Ab 再回到 C，听感非常连贯；同时七和弦让整体更柔和，最后 Fm/Ab 带来一点忧伤的阴影，再回到 C 时会有「落地」的满足感。适合想要明显提升设计感、但不想改变整体温暖气质的场景。
- 依据：低音级进下行 C → G/B → Am → F/A → Fm/Ab → C，低音依次为 C → B → A → A → Ab → C，在保持和声功能不变的前提下显著提升设计感 [来源3]。；七和弦不会改变功能关系，只是让听感比三和弦更「软」 [来源5]。；把 IV 换成 iv（Fm 或 Fm/Ab）属于调式借用，引入新色彩但不破坏框架 [来源1]。

**机器校验**：编造引用 0 条、调外和弦 0 个

### gen.advice.002 —— 明确的修改方向：增加收尾感

**用户输入**

```text
创作目标：想要结尾更有收束感
和弦进行：C | G | Am | F
用户水平：some
```

**系统输出**

**分析**：当前作品是 C 大调的 I–V–vi–IV 进行（C | G | Am | F），这是流行与民谣里非常常见的四和弦循环，整体听感明亮、顺畅，但正因为它是「循环型」走向，天然缺少一个明确的句号，所以你会觉得结尾不够收束。

**问题**：
- 最后停在 IV（F）上，F 本身不是主和弦，也不是属和弦，它更像「话说到一半」，天然没有结束感。
- 整段没有出现 V → I 或 IV → I 这类终止动作，缺少「把话说完」的和声公式。
- 四个和弦功能上偏向「起—承—转—再转」，没有回到主和弦 C 的落脚点。

**建议 A：把最后一个 F 换成 G，再做 V → I**

- 和弦：`C | G | Am | G | C`
- 特点：在原有循环末尾插入一个属和弦再回主和弦，用最经典的句号收尾。
- 解释：通俗解释：原来最后停在 F 上像是「然后呢？」，现在改成 G 再回 C，就像说话时先扬一下再落下来，耳朵会明显感到「结束了」。
- 依据：V → I 是完全终止（Authentic 终止式（Cadence）），是最典型的句号，结束感最强 [来源1]。；终止式只需要改动最后两个和弦，不需要重写整段 [来源2]。；民谣里 I → IV → V → I 就是靠这个动作获得明确的起承转合 [来源4]。

**建议 B：把最后一个 F 换成 F → G → C，做 IV → V → I**

- 和弦：`C | G | Am | F | G | C`
- 特点：保留原曲的 F，但在它后面补上 G 和 C，形成完整的下属—属—主收束。
- 解释：通俗解释：F 本身是柔和的下属和弦，让它先出现，再经过 G 这个「紧张」的和弦，最后落到 C，就像先铺一层软垫再稳稳坐下，收束感比直接 V → I 更饱满。
- 依据：IV → V → I 是功能完整的终止进行，下属铺垫、属制造期待、主解决 [来源4]。；终止式决定结束感的强弱，V → I 为完全终止，结束感最强 [来源1]。；只改最后两个和弦就能让段落「有结束感」 [来源2]。

**建议 C：把最后一个 F 换成 Fm，做 IV → iv → I 的变格色彩**

- 和弦：`C | G | Am | F | Fm | C`
- 特点：用平行小调借来的 iv（Fm）软化结尾，收束同时带一丝忧伤。
- 解释：通俗解释：F 换成 Fm 后，最后回 C 时会多一层「淡淡的惆怅」，像句号后面还留了一点余味，适合想要温柔收尾而不是干脆结束的段落。
- 依据：IV → I 是变格终止（Plagal 终止式（Cadence）），柔和、常用于结尾的「阿门」感 [来源1]。；把 F 换成 Fm 属于从平行小调借用和弦（Modal Borrowing），会改变结尾的色彩 [来源5]。；日系与 City Pop 常用这类借用与延伸音制造「绕路感」 [来源5]。

**机器校验**：编造引用 0 条、调外和弦 0 个

### gen.advice.003 —— 小调作品

**用户输入**

```text
创作目标：想让它更有层次，不要太平
和弦进行：Am | F | C | G
用户水平：some
```

**系统输出**

**分析**：你的进行 Am | F | C | G 是 A 小调里最经典的 i → VI → III → VII，功能上完全正确、情绪上从伤感切入到相对开阔，是一个很稳的骨架。问题不在「错」，而在「平」——四个和弦都是原位三和弦，低音走的是 A → F → C → G，全是四度五度的大跳，功能清楚但连贯性弱；加上每个和弦都是根音位置、没有七音九音，色彩也比较单一。

**问题**：
- 低音全是大跳（A→F→C→G），缺少级进线条，听感『功能清晰但连贯性弱』，这正是它听起来普通的原因之一 [来源1][来源2]
- 四个和弦都是原位三和弦，没有加音、没有转位，和声色彩变化太小 [来源3]
- 四个和弦每小节一个、时值平均，没有张力累积或释放的设计，层次感不足 [来源1][来源3]

**建议 A：低音级进下行，把骨架『缝』起来**

- 和弦：`Am | F/A | C/G | G/B`
- 特点：和声功能完全不变，只换低音，改动成本最低、几乎不会改坏。
- 解释：通俗解释：和弦还是那四个，但低音从 A → A → G → B 走出一条更平滑的线，听起来像有一条看不见的线把四个和弦串起来，不再是一块一块跳。这是四种加法里最安全的一档。
- 依据：换低音（Inversion / Bass Line）能在保持和声功能不变的前提下增加连贯性与设计感 [来源3]；低音线是听感连贯性的主要来源，也是改动成本最低的增色手段之一 [来源1]；级进下行 / 平滑低音线条能显著提升『设计感』 [来源1][来源2]

**建议 B：加音变七和弦，让色彩柔和起来**

- 和弦：`Am7 | Fmaj7 | Cmaj7 | G7`
- 特点：功能关系不动，只把三和弦升级成七和弦，听感立刻从『干净』变成『柔和、有空气感』。
- 解释：通俗解释：三和弦像白开水，七和弦像加了点蜂蜜。Am7、Fmaj7、Cmaj7 会变得梦幻柔和，最后的 G7 带一点想回到 Am 的拉力，循环感更强。改动很小，但耳朵能明显听出层次。
- 依据：加音（Extension）：三和弦变七和弦，改动最小，听感变柔和、梦幻，功能关系完全不变 [来源3]；Cmaj7 → G/B → Am7 → Fmaj7 这类写法功能关系不变，但色彩明显更柔和 [来源2]；四种加法排序建议先试一、二，它们几乎不会『改坏』 [来源3]

**建议 C：借用平行小调，给最后一步加一层阴影**

- 和弦：`Am | F | C | G`
- 特点：把最后一个 G 换成 Gm（从平行小调借来的和弦），整体从『伤感→开阔』变成『伤感→开阔→突然一沉』。
- 解释：通俗解释：前面三个和弦不动，只在最后一步把明亮的大三和弦换成小三和弦，会多一丝忧伤，像一句话说到最后突然低下去。变化幅度比前两个方向大，但情绪层次最明显。
- 依据：替换（Substitution）：把 IV 换成 iv（调式借用），引入新的色彩但不破坏框架 [来源3]；C → G → Am → Fm 最后一步借用平行小调的 iv，加一层阴影 [来源2]；三、四类改动听感变化更明显，需要确认是否接受更大幅度的改动 [来源3]

**机器校验**：编造引用 0 条、调外和弦 0 个

### gen.advice.004 —— 带旋律输入（§3.1.3 的进阶示例）

**用户输入**

```text
创作目标：保持温暖但更有记忆点
和弦进行：C | G | Am | F
旋律：E4 G4 A4 G4 E4
用户水平：some
```

**系统输出**

**分析**：当前作品是 C 大调最经典的「四和弦进行」I–V–vi–IV 进行（C | G | Am | F），温暖、稳定、听感友好。旋律 E4 G4 A4 G4 E4 以级进为主，落音回到 E，与 C 和弦形成大三度，整体情绪明亮而柔和。问题在于：这四个和弦全是三和弦，功能关系是教科书式的正格进行，缺少七和弦、延伸音、低音线条或副属和弦带来的「个性标记」，因此容易被听成「像很多歌」而不是「像这一首」。

**问题**：
- 和声全是三和弦，色彩偏「素」，缺少七和弦或延伸音带来的柔和、梦幻层次。
- 低音线是 C→G→A→F 的跳进，缺少级进下行的连贯性与设计感。
- 旋律动机 E4 G4 A4 G4 E4 基本是原样重复加回落，没有模进或变奏，记忆点不够强。
- IV 级用大三和弦 F，缺少小下属 iv 或副属和弦带来的「绕路感」，情绪转折偏平。

**建议 A：七和弦柔化 + 低音级进下行**

- 和弦：`Cmaj7 | G/B | Am7 | Fmaj7`
- 特点：改动成本最低的「加音 + 换低音」组合，功能关系完全不变，只把三和弦升级为七和弦，并让低音走 C→B→A→F 的级进下行。
- 解释：通俗解释：听起来会从「干净明亮」变成「柔软、带一点夜晚感」。Cmaj7 比 C 更软，Am7 比 Am 更忧伤但不刺耳，Fmaj7 比 F 更松弛。低音从 C 到 B 到 A 是级进下行，像一条平滑的线把四个和弦串起来，听感更有「设计感」，但不会破坏原来温暖的大调框架。
- 依据：三和弦叠一个三度音得到七和弦，不改变功能关系，只增加柔和、梦幻或爵士色彩 [来源3]。；把 C 换成 G/B 属于换低音（Inversion / Bass Line），低音级进下行增加连贯性，和声实质不变 [来源1]。；Cmaj7 仍是 I 级、仍然稳定，只是听感比 C 更软，是「保持原样但更有味道」的最省力做法 [来源3]。

**建议 B：局部借用小下属 + 副属和弦插入**

- 和弦：`Cmaj7 | G7 | Am7 | Fmaj7`
- 特点：在目标和弦前插入副属和弦 E7 → Am，并把 IV 换成 iv（Fm → Fmaj7 前的 Fm 可作过渡），制造局部推进与「绕路感」。
- 解释：通俗解释：G7 比 G 多了一层「要求解决」的紧张感，落到 Am7 时会更满足。如果在 Am 前插入 E7（V/vi），会多一次「绕路再回家」的推进感，像日系流行里常见的「王道进行」味道。把 F 换成 Fm（从平行小调借来的和弦），会多一丝忧伤，但整体大调框架还在，所以是「忧郁但温暖」而不是「彻底变暗」。
- 依据：在目标和弦前插入副属和弦（V/vi），制造局部推进，属于改动成本较高的第四类手法 [来源1]。；日系 / City Pop 大量运用副属和弦与调式借用制造「绕路感」，王道进行 IVmaj7 → V7 → iii7 → vi 是最具辨识度的走向 [来源2]。；保留大调框架（I、V 级仍在），只在局部引入小调色彩，是「忧郁但温暖」的技术路径 [来源4]。

**建议 C：旋律动机模进 + 和声节奏放宽**

- 和弦：`Cmaj7 | G/B | Am7 | Fmaj7`
- 特点：和声沿用建议 A 的柔化版本，重点改旋律：把 E4 G4 A4 G4 E4 这个动机做一次模进（整体移高或移低），并在句尾用变奏回落，形成「好记又耐听」的副歌感。
- 解释：通俗解释：原旋律像一句话说了两遍，第二遍没有新信息。把动机整体移高几度再重复，会产生推进感，像副歌被抬起来；句尾再变奏回落，既有统一性又有新鲜感。配合七和弦与低音下行，整体会从「温暖但普通」变成「温暖且有记忆点」。
- 依据：动机发展常用重复、模进、变奏、扩展四种手法；模进把动机整体移高或移低若干音级重复，产生推进感，是流行歌副歌最常用的手法 [来源5]。；主歌用一个动机反复，副歌用模进把同一个动机抬升成高潮，全曲统一性来自同一个素材，而不是靠堆砌 [来源5]。；七和弦不会改变功能关系，Cmaj7 仍然是 I 级，仍然稳定，只是听感比 C 更「软」 [来源3]。

**机器校验**：编造引用 0 条、调外和弦 0 个

### gen.advice.005 —— 已含七和弦的进阶作品

**用户输入**

```text
创作目标：再丰富一点
和弦进行：Cmaj7 | G | Am7 | Fmaj7
用户水平：some
```

**系统输出**

**分析**：你的进行 Cmaj7 → G → Am7 → Fmaj7 是 C 大调里最稳的「1-5-6-4」走向，本身已经用上了大七和小七，听感偏柔和、明亮，属于「不会出错」的配置。问题在于：G 是唯一的三和弦，密度上比前后三个七和弦「薄」了一截；同时四个和弦全部是原位（Root Position，即最低音就是和弦根音），低音线是 C-G-A-F，跳进较多，缺少一条连贯的「线」。整体色彩偏「平」，也就是每个和弦都在预期之内，没有一处让人耳朵一亮的「绕路」。

**问题**：
- G 是唯一的纯三和弦，夹在三个七和弦中间，听感上会显得比前后「空」一点，色彩密度不统一。
- 四个和弦全为原位，低音 C→G→A→F 以跳进为主，缺少级进（Stepwise，相邻音级移动）的连贯感。
- 全程没有离开 C 大调的音，缺少「借来的颜色」，情绪层次单一，容易听完就忘。

**建议 A：把 G 升级成 G7，并让低音走一条下行线**

- 和弦：`Cmaj7 | G/B | Am7 | Fmaj7`
- 特点：改动成本最低的一档：只动低音和七音，和声功能关系完全不变。
- 解释：通俗解释：G 变成 G/B 之后，最低音从 G 挪到 B，整条低音线就变成 C→B→A→F，前三步是一格一格往下走的，听起来像有人牵着你的手往下走楼梯，比原来「跳来跳去」顺得多。同时 G 加上七音变成 G7，紧张感更强，会更想往 Am7 落，推进感更明确。这是「保持原样但更有味道」的最省力做法。
- 依据：三和弦叠一个三度音得到七和弦，G7 属于属七，紧张、要求解决，功能上仍是 V 级 [来源2]；换低音（Inversion）属于改动成本第二低的手法，和声实质不变，只增加低音连贯性与设计感 [来源1]；低音级进下行是日系与 City Pop 的常见增色要点 [来源3]

**建议 B：把 Fmaj7 换成 Fm（从平行小调借来的和弦）**

- 和弦：`Cmaj7 | G | Am7 | Fm`
- 特点：只换最后一个和弦，从 C 大调的平行小调「借」来一个小下属，瞬间多一层阴影。
- 解释：通俗解释：Fmaj7 是明亮温暖的大和弦，换成 Fm 之后，同一个根音 F，但三音从 A 降到了 Ab，整个和弦一下子暗下来。因为前面三个和弦都是大调色彩，最后突然来这么一下，会有一种「话说到一半忽然叹气」的效果，忧郁但不至于沉闷——因为 I 级和 V 级还在，大调框架没塌。
- 依据：把 IV 换成 iv 属于替换（Substitution）中的调式借用，引入新色彩但不破坏框架，改动成本中等 [来源1]；小下属和弦 iv 是制造忧郁感的经典手段；保留 I、V 级可让忧郁「带温度」而不沉闷 [来源4]

**建议 C：在 Am7 前插入副属和弦 E7，制造局部推进**

- 和弦：`Cmaj7 | G | E7 | Am7 | Fmaj7`
- 特点：改动最大但效果最抓耳：给 vi 级配一个「专属的属和弦」，绕一小段路再回来。
- 解释：通俗解释：E7 是 Am 的属和弦，本来 Am7 前面是 G，现在先用 E7 把 Am 单独「点名」一次，再到 Am7，会有一种「特意绕过去」的感觉，情绪被推了一下才落下。相当于在原来的直路上加了一个小弯，路还是那条路，但风景变了。注意 G→E7 这一步跨度较大，如果觉得太突兀，可以先把 G 改成 G7 过渡。
- 依据：在目标和弦前插入副属和弦（V/vi）属于插入（Insertion），制造局部推进，听感变化明显 [来源1]；副属和弦是日系 / City Pop 制造「绕路感」的高频手法，典型如 E7 → Am [来源3]

**机器校验**：编造引用 0 条、调外和弦 0 个

### gen.advice.006 —— 零基础用户使用进阶入口

**用户输入**

```text
创作目标：我不懂乐理，就是觉得听着有点平淡
和弦进行：C | G | Am | F
用户水平：zero
```

**系统输出**

**分析**：你现在用的是 C → G → Am → F 这四个和弦，每个都是最基础的三和弦版本。听起来是顺的，没有怪音，情绪也是明亮的、偏温暖的。但因为四个和弦的‘厚度’都一样，而且每个和弦都踩在正拍上、低音都是根音往下掉（C→G→A→F），所以耳朵会觉得‘一路平着走’，没有起伏，也没有惊喜。简单说：方向是对的，但每个站台长得太像了。

**问题**：
- 四个和弦全是三和弦，厚度一样，没有‘明暗变化’，听起来像四张一样的明信片。
- 低音从 C 到 G 到 A 到 F，跳得比较直，没有一条平滑的线，耳朵会觉得‘硬’。
- 和弦之间缺少‘挂一下再落地’的小动作，所以整体缺少‘呼吸感’。

**建议 A：给每个和弦加一层‘柔光滤镜’**

- 和弦：`Cmaj7 | G/B | Am7 | Fmaj7`
- 特点：保持原来的走向不变，只把每个和弦升级成更厚的版本，并让低音走成一条下行的线。
- 解释：听起来会从‘干净直白’变成‘柔和、梦幻、有质感’。走向没变，只是每个和弦多了一个音，就像给照片加了一层柔光。低音从 C 到 B 到 A 到 F，变成一条慢慢往下走的线，耳朵会觉得顺滑很多。
- 依据：给明亮的大调和弦加一个音会变得更柔和、更暖 [来源4]；低音排成一条平缓的线，能让和弦之间连得更顺 [来源4]；只改和弦的‘厚度’，不改走向，是最容易上手、效果最明显的改法 [来源1]

**建议 B：在最后一步‘绕个弯再回家’**

- 和弦：`C | G | Am | F | Fm | C`
- 特点：在原来的四步后面，加一个‘突然变暗’的小转弯，再回到 C，制造一次情绪起伏。
- 解释：听起来会在结尾处‘心里一沉’，然后突然被拉回明亮，像说完一句话后轻轻叹口气再笑。前面四步照旧，只是在最后把 F 换成 Fm，再回到 C，整首歌就有了一个‘记忆点’。
- 依据：突然冒出一个不属于这个调的和弦，暖意会被打破，但用得好就变成情绪起伏 [来源4]；音乐情绪靠‘亮↔暗’的对比来推动，一直亮反而会显得平 [来源3]；和弦进行像说话的起承转合，最后一步绕一下再落地，会更有‘说完了一句话’的感觉 [来源5]

**建议 C：把速度放慢，让和弦‘多待一会儿’**

- 和弦：`C | G | Am | F`
- 特点：和弦完全不动，只把每个和弦弹的时间拉长一倍，或者每个和弦先弹根音、再弹完整和弦。
- 解释：听起来会从‘散步’变成‘翻相册’。同样的四个和弦，走慢一点、每个多停一会儿，耳朵就有时间品味每个和弦的颜色，平淡感会被‘从容感’取代。这是最省事的改法，一个音都不用换。
- 依据：速度决定歌走起来的感觉：像翻相册、像散步、还是像走路 [来源2]；情绪由和弦明暗、旋律上下、速度快慢三样一起决定，改速度就能改情绪 [来源3]；写歌只需要做四个决定，改其中任何一个都比从零想容易 [来源1]

**机器校验**：编造引用 0 条、调外和弦 0 个

### gen.advice.007 —— 目标与和弦关系较弱

**用户输入**

```text
创作目标：想让它更适合毕业的感觉
和弦进行：C | G | Am | F
用户水平：some
```

**系统输出**

**分析**：当前作品是 C 大调的 I–V–vi–IV 进行（C | G | Am | F），也就是流行音乐里最常见的「四和弦循环」。它本身没有错，情绪偏明亮、顺滑、带一点温柔的起伏，适合抒情流行歌。但它的「毕业感」目前是通用型的——像是任何一首青春励志歌都能套进去，缺少「告别时那一下不舍」和「最后释然」的明确对比。速度上如果按 60~85 BPM 的中慢速处理，会更接近翻相册或散步的听感 [来源2]。

**问题**：
- 整首都在大调色彩里打转，没有小调和弦来承载「不舍」，情绪转折不够明显 [来源3]。
- I–V–vi–IV 进行 的循环太顺、太熟，缺少一个「悬念 → 答案」的张力配对，副歌结尾没有完全终止或欺骗终止来落地 [来源5]。
- 如果旋律一直停在同一个音区，副歌没有音区抬升，情绪推进只能靠音量，容易平 [来源4]。

**建议 A：把第二个和弦换成 iii，制造「回头看一眼」的犹豫**

- 和弦：`C | Em | Am | F`
- 特点：用 iii 代替 V，让「向前走」之前先有一拍犹豫，适合主歌叙述段。
- 解释：通俗解释：C 之后直接接 Em，听起来不像 G 那么「推着走」，而是像脚步顿了一下、回头看了一眼。Em 是小调和弦，带一点忧伤，正好对应毕业时「舍不得」的那一下。术语旁注：iii 是 C 大调的三级小和弦，属于小调色彩，常用来替代 V 做情绪缓冲 [来源3]。
- 依据：主歌用小调和弦承载「不舍」，副歌回到大调和弦承载「接受与向前」 [来源3]。；中慢速下每小节一个和弦，给歌词留出叙述空间 [来源1]。

**建议 B：副歌结尾用 V → vi 欺骗终止，保留一丝不舍**

- 和弦：`C | G | Am | F | G | Am`
- 特点：在原本的 F 之后加一个 G → Am，让副歌不落在 C 上，而是落在 Am 上。
- 解释：通俗解释：本来 F 之后回到 C 会像「事情说完了、放下了」，但改成 G → Am，听起来像话到嘴边又咽回去，情绪没有完全落地，反而更戳人。术语旁注：V → vi 叫欺骗终止（Deceptive 终止式（Cadence）），它不解决到主和弦，而是绕到关系小调，制造「差一点就释然」的听感 [来源1][来源5]。
- 依据：副歌结尾使用完全终止（V → I）让「向前」落地；若想保留一丝不舍，可用欺骗终止（V → vi）收尾 [来源1]。；张力与释放要在同一乐句内配对，有悬念就必须有答案 [来源5]。

**建议 C：主歌小调化，副歌回大调，做「伤感 → 释然」的转向**

- 和弦：`Am | F | C | G | C | G | Am | F`
- 特点：主歌用 Am → F → C → G 的小调色彩，副歌回到 C → G → Am → F 的大调色彩，形成明显转折。
- 解释：通俗解释：主歌听起来像翻旧照片、有点闷、有点想哭；副歌一进来突然亮起来，像终于接受「要往前走了」。术语旁注：这是「小调色彩 → 大调色彩」的转向，不是整首改小调，而是主歌用 Am、F 这类小调或中性和弦，副歌回到 C、G 这类大调和弦 [来源3]。
- 依据：告别 / 毕业主题的情感结构是回忆 → 不舍 → 接受 → 向前，对应主歌小调、副歌大调 [来源1]。；转折处可用 iv → I 或 V → I 的终止关系，让「释然」有落点 [来源3]。；副歌整体抬高音区，用音区落差制造情绪推进，不必靠更大音量 [来源4]。

**机器校验**：编造引用 0 条、调外和弦 0 个

### gen.advice.008 —— 指定调性

**用户输入**

```text
创作目标：想增加色彩
和弦进行：G | D | Em | C
用户水平：some
```

**系统输出**

**分析**：这是一条非常标准的 I–V–vi–IV 进行 进行（G | D | Em | C），在 G 大调里功能链条清晰：G 是主和弦（Home，稳定），D 是属和弦（Dominant，制造回归的拉力），Em 是六级小和弦（vi，常被当作「替代主音」的柔软落点），C 是下属和弦（Subdominant，把情绪往外推开一点）。它本身没有错，情绪走向是「稳定 → 紧张 → 忧伤 → 开阔」，是流行歌里覆盖率极高的骨架。问题不在「对不对」，而在「辨识度」——四个和弦都是三和弦原位，低音走 G→D→E→C，其中 G→D 是五度跳进、D→E 是二度上行、E→C 是三度下行，线条不够连贯，所以听起来会偏「默认配置」[来源3][来源4]。

**问题**：
- 全部使用三和弦原位，没有加音或七音，听感偏「素」，缺少柔和或梦幻的层次 [来源5]
- 低音线以跳进为主（G→D、E→C），缺少级进的黏合感，段落之间的「设计感」不足 [来源4]
- 四个和弦的功能关系完全没被强调或改写，情绪起伏较平，副歌若直接套用会显得推进力不够 [来源1]

**建议 A：加音变软（三和弦升七和弦）**

- 和弦：`Gmaj7 | D7 | Em7 | Cmaj7`
- 特点：改动成本最低，功能关系一字不动，只把「硬度」降下来。
- 解释：通俗解释：G 变 Gmaj7 后，原本干脆的稳定感会多一层柔和的「尾巴」，像灯光从白光换成暖黄；Em 变 Em7 会更忧伤一点；Cmaj7 则把 IV 的开阔感变得梦幻。D 保留成 D7（属七）反而更好，因为它本来就该紧张、要求解决，加了七音后回归 G 的拉力更强。整条进行仍然是 I–V–vi–IV 进行，只是每一块都「软」了一档。
- 依据：在三和弦上再叠一个三度音即得七和弦，比三和弦多一层「未解决」的听感，但不改变功能关系，Cmaj7 仍然是 I 级、仍然稳定 [来源5]；四种常用七和弦色彩：Cmaj7 柔和明亮、Am7 柔和忧伤、G7 紧张要求解决、Dm7 铺垫感强 [来源5]；加音（Extension）是四种增色手法里改动最小的一种，几乎不会「改坏」原有框架 [来源1]

**建议 B：换低音做级进下行**

- 和弦：`G | D/F# | Em | C`
- 特点：和声实质不变，但低音变成 G→F#→E→… 的平滑下行，立刻有「编曲感」。
- 解释：通俗解释：把 D 换成 D/F#（也就是让 F# 走低音），低音就从 G 一路滑到 F#、再滑到 E，像下楼梯一样顺。原来 G→D 是五度大跳，听起来功能清楚但有点「断」；换成级进后，四个和弦被一条低音线串起来，连贯性明显提升，这是改动成本很低、效果却很明显的做法。
- 依据：换低音（Inversion / Bass Line）属于四种增色手法中成本第二低的一种，和声实质不变，只增加连贯性与「设计感」 [来源1]；低音线是听感连贯性的主要来源；级进下行能显著提升设计感，而跳进低音（如默认的 G→D）功能清晰但连贯性弱 [来源4]；低音级进下行的经典案例：C → G/B → Am → F/A → Fm/Ab → C，低音依次为 C→B→A→A→Ab→C [来源4]

**建议 C：局部替换 + 插入副属，制造推进**

- 和弦：`G | D | Em | A7 | C`
- 特点：改动幅度最大，但能把 IV 前的情绪推高一档，适合副歌或桥段。
- 解释：通俗解释：在 C 前面插一个 A7，A7 是「指向 D 的属和弦」，但这里它不解决到 D，而是拐去 C，会制造一种「差一点就要回去、结果没回去」的悬念，色彩立刻变浓。另外也可以把 C 换成 Cm（从平行小调借来的和弦），会多一丝忧伤，因为 G 大调的平行小调是 G 小调，Cm 里的降 E 音是借来的颜色。
- 依据：替换（Substitution）如把 IV 换成 iv（调式借用），引入新色彩但不破坏框架；插入（Insertion）如在目标和弦前插入副属和弦（V/vi），制造局部推进 [来源1]；替换与插入的听感变化比加音、换低音更明显，需要确认是否接受更大幅度的改动 [来源1]；和弦进行决定情绪的走向（稳定还是紧张）与段落的划分（哪里是句号、哪里是逗号） [来源3]

**机器校验**：编造引用 0 条、调外和弦 0 个
